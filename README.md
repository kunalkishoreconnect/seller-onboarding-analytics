# Seller Onboarding Analytics
Synthetic product analytics portfolio project. No Shiprocket data or affiliation.

Run: `pip install -r requirements.txt` then `streamlit run app.py`.
Deploy repository root app.py on Streamlit Community Cloud after uploading package contents to GitHub.

Read INSIGHT_AND_EXPERIMENT.md for computed findings, limitations and experiment planning.
Run analysis.sql on analytics.sqlite to reproduce funnel, segmentation, time-to-shipment and repeat-shipment cohort queries.
All data is synthetic; no uplift is claimed. README and SQL are suitable public portfolio artifacts.
